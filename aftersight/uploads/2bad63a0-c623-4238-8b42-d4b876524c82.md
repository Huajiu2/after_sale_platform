# 七、食品保健&医疗器械专项售后补充规则
## 1.1 医疗器械通用售后标准
### 1.1.1 七天无理由适用边界
1. 未拆封一次性无菌密封包装、未开封耗材类器械支持7天无理由；
2. 已拆封无菌包装、接触伤口/黏膜/血液器械，不适用七天无理由；
3. 定制矫正器械、医用定制牙套、矫形支具不支持无理由退货；
4. 家用非接触类器械（体重秤、血压计外壳未拆封）可正常无理由退换。

七日计算规则：物流签收次日零时起算，满168小时为完整7天。

### 1.1.2 商品完好判定
1. 整机无划痕、磕碰、进水、私自拆修；设备序列号、防伪标完整；
2. 无菌耗材内外塑封完整，无开封、破损、渗漏；
3. 配套说明书、充电线、电极片、收纳盒、合格证全部齐全；
4. 器械配套一次性用品已拆封使用，整机即便完好也无法无理由退货。

### 1.1.3 三包时效（医用器械）
- 7日退货：签收7日内出现非人为性能故障，可全额退货；
- 15日换货：签收15日内非人为故障，免费换新；
- 1年整机保修：主机1年内非人为损坏免费维修；一次性耗材不纳入保修范围。

### 1.1.4 质量问题举证要求
1. 故障实拍视频/照片，清晰展示设备报错、失灵、数值异常；
2. 品牌官方售后网点出具检测报告（涉及电路、传感器故障必须提供）；
3. 收到货当场破损需同步上传物流面单+外包装破损照片；签收超过48小时破损不予认定物流责任。

## 1.2 保健品/滋补品细分售后
### 1.2.1 支持无理由退货条件
1. 商品原厂一次性密封外包装完整未拆封，防伪未刮开；
2. 商品未过期、无受潮、无挤压破损；
3. 燕窝、海参、冬虫夏草、鲜参等干货滋补品**一律不支持七天无理由**，仅质量问题可售后。

### 1.2.2 不支持无理由场景
1. 铝箔、独立胶囊板、瓶装内盖已开封；
2. 粉剂、口服液已开盖食用；
3. 商家页面已显著标注临期清仓商品；
4. 购买时自主选择拆封试吃装。

### 1.2.3 质量赔付标准
1. 商品霉变、虫蛀、异味、分层、液体浑浊：全额退款，商家承担来回运费；
2. 包装漏气、破损导致产品污染：按受损比例阶梯赔付；
3. 成分与详情页标注严重不符，支持退货退款并平台处罚商家；
4. 单纯口感、气味个人不适应，不属于质量问题，不予售后。

## 1.3 计生健康类商品规则
### 1.3.1 无理由退货限制
避孕套、润滑液、验孕试纸、排卵试纸、私处护理凝胶等一次性卫生计生用品，拆封后不支持七天无理由；未拆封密封包装可正常申请无理由。

### 1.3.2 质量问题判定
1. 套体破损、漏液、包装漏气；
2. 试纸失效、显色异常、批次过期；
3. 护理产品出现分层、沉淀、刺鼻异味；
以上情形凭实物照片可直接办理退货，运费商家承担。

## 1.4 运费权责划分
1. 买家单纯不想要、完好未拆封：买家承担退货运费；
2. 质量问题/漏发配件/描述不符：商家承担全部往返运费；
3. 赠品丢失、破损：按商品标价折价扣款，不影响主商品退货；
4. 已开具纸质发票，买家退货需寄回发票，否则扣除对应税费。

## 1.5 禁止售后行为
1. 拆封无菌耗材、计生用品后恶意申请无理由退货；
2. 人为进水、摔损、私自拆机后谎称设备质量故障；
3. 大量囤货、短期高频退换保健品/器械滥用售后权益；
4. 以“使用后身体不适”为由无凭证退货（需二级及以上医院诊断证明）。

## 1.6 AI审核专项判定要点
1. 区分器械是否无菌耗材，拆封直接驳回无理由；
2. 滋补干货（海参/虫草）无论是否拆封，无质量问题一律驳回无理由；
3. 器械故障工单，缺少检测报告且图片无法证明故障 → 转人工审核；
4. 保健品过敏诉求，未提供医院诊断证明 → 驳回；
5. 临期商品需核对商品页是否显著标注临期，已标注则不支持无理由。

## 1.7 人工介入场景
1. 买家反馈使用医疗器械造成皮肤红肿、刺痛、身体不适；
2. 订单实付金额≥5000元高端医用器械；
3. 商家拒绝售后且双方举证冲突；
4. 买家投诉商品虚假宣传、成分造假；
5. 同一用户1个月内3次以上同类商品售后申请。

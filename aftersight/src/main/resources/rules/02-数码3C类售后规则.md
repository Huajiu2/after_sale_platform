# 二、数码3C类商品售后专项规则

## 2.1 手机通讯

### 2.1.1 退换货时限
- **7日无理由退货**：自签收次日起7日内，商品完好、包装配件齐全
- **7日质量问题退货**：自签收次日起7日内，经检测确认为非人为质量问题
- **15日质量问题换货**：自签收次日起15日内，经检测确认为非人为质量问题
- **一年保修**：自激活次日起一年内，非人为质量问题免费维修

### 2.1.2 激活与完好标准
- **激活定义**：用户第一次连接互联网使用手机的时间（包括WIFI、移动数据网络）
- **无理由退货特殊要求**：已激活的手机不适用七天无理由退货
- 进网许可证/入网标签不得损坏
- 商品序列号（SN/IMEI/MEID）不得被涂改、损坏
- ID账号须退出登录，清除个人数据

### 2.1.3 不适用场景
- 已激活使用（无质量问题）
- 外观有明显划痕、磕碰、摔损
- 进网许可证已损坏
- 无法解除屏幕锁或账户锁
- 私自拆修、进液
- 配件缺失

### 2.1.4 三包凭证要求
- 有效购买凭证（发票或电子购买记录）
- 三包凭证齐全
- 维修记录完整

## 2.2 电脑/平板/笔记本

### 2.2.1 退换货时限
- 7日无理由退货（Windows/Office未激活）
- 7日质量问题退货
- 15日质量问题换货
- 一年保修

### 2.2.2 特殊完好要求
- Windows系统或Office主机未激活
- 系统未注册、未登录个人账号
- 外观无划痕、磕碰
- 所有配件齐全（电源适配器、数据线、触控笔等）
- 包装盒完好

### 2.2.3 不适用场景
- 系统已激活、已注册
- 外观有明显使用痕迹
- 已安装个人软件、存储个人数据
- 序列号标签损坏
- 私自拆机升级硬件

## 2.3 数码相机/摄影器材

### 2.3.1 退换货条件
- 快门次数未超过合理检查范围（通常<100次）
- 机身无划痕、无磕碰、无磨损
- 镜头镜片无划伤、无霉点、无灰尘
- 传感器无坏点
- 所有原装配件齐全（电池、充电器、数据线、肩带等）

### 2.3.2 不适用场景
- 快门次数超过合理检查范围
- 机身有明显使用磨损
- 保修贴纸被撕毁或破损
- 私自拆修

## 2.4 智能穿戴/耳机/音箱

### 2.4.1 退换货条件
- 耳机、耳塞类：外包装未拆封（因涉及个人卫生）
- 智能手表/手环：未激活配对、外观完好
- 音箱：外观完好、配件齐全

### 2.4.2 不适用场景
- 耳机类商品拆封试用（属于拆封后影响人身安全的商品）
- 智能穿戴已激活配对
- 防水性能因人为损坏
- 序列号不匹配

## 2.5 AI审核要点
1. 判断手机是否已激活 → 已激活则仅支持质量问题退换
2. 判断电脑系统是否已激活 → 已激活不支持无理由退货
3. 检查外观损伤为人为还是非人为 → 人为损伤不纳入质量问题
4. 配件是否齐全 → 缺失配件需折价处理
5. 保修凭证是否完整 → 影响三包服务范围
6. 耳机/个人卫生类商品拆封后不支持无理由退货
7. 审核结论优先级：法律强制规定 > 平台规则 > 商家承诺

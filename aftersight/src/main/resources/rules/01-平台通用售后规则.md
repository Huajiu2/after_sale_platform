# 一、平台通用售后规则文档

## 1.1 七天无理由退货

### 1.1.1 适用范围
- 消费者为生活消费需要通过网络购买商品，自收到商品之日起七日内，有权依法申请无理由退货
- 七日期间自物流显示签收商品的**次日零时起计算，满168小时为七天**

### 1.1.2 不适用情形
以下商品不适用七日无理由退货规定：
1. 消费者定作的商品（定制类、定做类商品）
2. 鲜活易腐的商品（鲜花绿植、水产肉类、新鲜蔬果、活体类等）
3. 在线下载或者消费者拆封的音像制品、计算机软件等数字化商品
4. 交付的报纸、期刊
5. 拆封后易影响人身安全或者生命健康的商品，或者拆封后易导致商品品质发生改变的商品
6. 一经激活或者试用后价值贬损较大的商品
7. 销售时已明示的临近保质期的商品、有瑕疵的商品

### 1.1.3 商品完好标准
**通用完好标准：**
- 商品能够保持原有品质、功能
- 退回商品和相关配（附）件（如吊牌、说明书、三包卡、入网卡等）齐全
- 无受损、受污、刮开防伪、产生激活（授权）等情形
- 无难以恢复原状的外观类使用痕迹和不合理的个人数据使用痕迹
- 商品包装完整（原包装未缺失，包装整体结构完整）

**特殊商品包装保护：**
- 具有防伪性、唯一性、收藏纪念价值等特殊附加价值的包装，卖家可事前显著明示保护要求
- 卖家未事前显著明示的，按普通包装完整标准处理
- 卖家发货时使用厂商原包装，若签收时外包装已破损，卖家不得要求退货时外包装无破损

**不完好判定标准：**
- 食品（含保健食品）、化妆品、医疗器械、计生用品：必要的一次性密封包装被损坏
- 电子电器类：进行未经授权的维修、改动，破坏/涂改强制性产品认证标志、指示标贴、机器序列号等，有难以恢复原状的外观类使用痕迹，或者产生激活、授权信息、不合理的个人使用数据留存等数据类使用痕迹
- 服装、鞋帽、箱包、玩具、家纺、家居类：商标标识被摘、标识被剪，商品受污、受损

### 1.1.4 运费规则
- 商品包邮：买家仅承担退货运费
- 商品未包邮：买家承担来回运费
- 商品质量问题/描述不符：运费由卖家承担
- 买家滥用会员权利：所有运费由买家承担
- 赠品遗失或破损：可折价处理，不影响商品退货
- 发票遗失：由买家承担相应税款

### 1.1.5 退款规则
- 消费者退回的商品完好的，网络商品销售者应当在收到退回商品之日起**七日内**向消费者返还已支付的商品价款
- 退款方式比照购买商品的支付方式
- 退货价款以消费者实际支出的价款为准
- 采用积分、代金券、优惠券等形式支付价款的，应当以相应形式返还

### 1.1.6 商家义务
- 不得擅自扩大不适用七日无理由退货的商品范围
- 应当在商品销售必经流程中设置显著的确认程序，供消费者对单次购买行为进行确认
- 如无确认，网络商品销售者不得拒绝七日无理由退货
- 对能够完全恢复到初始销售状态的七日无理由退货商品，可以作为全新商品再次销售
- 对不能够完全恢复到初始销售状态的商品而再次销售的，应当通过显著的方式将实际情况明确标注

## 1.2 质量问题退换货

### 1.2.1 三包规定
- **7日退货**：产品自售出之日起7日内，发生性能故障，消费者可以选择退货、换货或修理
- **15日换货**：产品自售出之日起15日内，发生性能故障，消费者可以选择换货或修理
- **一年保修**：产品自售出之日起一年内，发生性能故障，可享受免费维修服务

### 1.2.2 质量问题判定标准
- 商品功能性故障或性能故障
- 商品外观存在明显瑕疵、损伤（非人为）
- 商品与描述严重不符（材质、规格、功能等）
- 商品缺少必要配件或附件
- 商品存在安全隐患

### 1.2.3 质量问题举证责任
- 消费者主张质量问题的，应当提供初步证据（照片、视频等）
- 涉及功能性故障的，可由品牌授权服务网点出具检测报告
- 卖家对商品质量符合标准负有举证责任

## 1.3 售后处理时效

| 处理环节 | 时效要求 |
|---------|---------|
| 消费者发起退货通知 | 签收后7日内 |
| 卖家提供退货地址等信息 | 收到退货通知后及时（不超过系统限时） |
| 消费者退回商品 | 获得退货地址后及时（不超过系统限时） |
| 卖家退款 | 收到退回商品后7日内 |
| 质量问题举证 | 消费者发起后24小时内 |
| 换货处理 | 收到退回商品后15日内 |

## 1.4 禁止行为
- 滥用无理由退货规则损害经营者和他人合法权益
- 利用售后牟利或恶意申请、不诚信申请
- 未经消费者确认，擅自以商品不适用七日无理由退货为由拒绝退货
- 以消费者已拆封、查验影响商品完好为由拒绝退货（超出合理查验范围的除外）

## 1.5 争议处理原则
- 鼓励买卖双方协商解决
- 平台有权根据协调情况要求交易双方提供必要证明
- 平台介入时，按照"谁主张谁举证"原则分配举证责任
- 涉及食品安全、人身安全的争议，优先保护消费者权益
- 商家拒绝售后申请的，平台有权进行二次审核

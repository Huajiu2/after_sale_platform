# 二、家居家电类商品售后专项规则

## 5.1 大家电（空调/冰箱/洗衣机/电视等）

### 5.1.1 退换货时限
- **7日无理由退货**：商品未安装、配件齐全、外观完好
- **7日质量问题退货**：经检测确认为非人为质量问题
- **15日质量问题换货**：经检测确认为非人为质量问题
- **90天质量问题包换**（部分平台自营）：90天内质量问题可换货
- **一年保修**：非人为质量问题免费维修

### 5.1.2 完好标准
- 商品未经安装使用
- 空调内机与连接管接口处未打开
- 冰箱/洗衣机未通电使用
- 外观无划痕、磕碰、变形
- 所有配件齐全（遥控器、说明书、安装附件等）
- 包装材料完整

### 5.1.3 不适用情形
- 商品已安装（挂装空调、油烟机、热水器、洗碗机等）
- 已通电使用
- 外观有明显人为损坏
- 因安装不当造成的损坏
- 缺少安装附件

### 5.1.4 特殊说明
- 大家电需由专业安装人员上门安装，安装前请先检查外观
- 安装后非质量问题不支持无理由退货
- 尺寸问题：消费者未确认安装尺寸导致的安装问题，消费者承担相应责任
- 能效等级差异（以商品详情页标注为准）

## 5.2 小家电（厨房电器/生活电器）

### 5.2.1 退换货条件
- 商品外观完好、无划痕
- 配件齐全
- 无使用痕迹（未过水、未通电使用）
- 包装完好

### 5.2.2 特殊品类规则
| 品类 | 特殊要求 |
|------|---------|
| 净水器/滤水设备 | 未过水 |
| 厨房电器（电饭煲、空气炸锅等） | 未使用、无食物残留 |
| 个护健康（剃须刀、洁面仪等） | 未拆封（因接触皮肤） |
| 扫地机器人/吸尘器 | 未使用、滚刷无缠绕 |

### 5.2.3 不适用情形
- 商品已使用、已过水、已通电
- 个护健康类商品已拆封
- 缺少配件或说明书

## 5.3 家具/家装/建材

### 5.3.1 退换货条件
- 商品未使用、未安装
- 无人为损坏
- 标牌附件齐全
- 不影响二次销售

### 5.3.2 不适用情形
- 已安装、已使用
- 定制类家具（尺寸、颜色、材质定制）
- 组装过程中造成损坏
- 建材已切割、已涂刷、已施工
- 因测量不准导致的尺寸不符

### 5.3.3 特殊说明
- 大件家具运输过程中可能产生轻微磕碰，不影响使用的可不作为质量问题
- 实木家具的天然纹理、色差属正常现象
- 定制家具严格按照合同约定执行，消费者取消订单需承担相应损失

## 5.4 AI审核要点
1. 区分"大家电"和"小家电"→ 大家电安装后不支持无理由
2. 判断商品是否已安装 → 已安装大家电不接受无理由退货
3. 判断是否为定制类 → 定制家具不接受无理由退货
4. 审核外观损伤责任方 → 运输破损由物流负责，签收后发现的需48h内反馈
5. 判断功能性质检 → 需品牌官方售后检测报告
6. 个护健康类拆封后不支持无理由退货（皮肤接触类）
7. 净水器过水后不支持无理由退货

# 二、生鲜食品类商品售后专项规则

## 4.1 生鲜商品（蔬果/肉禽/水产）

### 4.1.1 售后时效要求
| 商品类型 | 申请时效 |
|---------|---------|
| 普通生鲜（蔬果、肉类） | 签收后**48小时**内 |
| 活鲜/水产 | 签收后**6小时**内 |
| 榴莲、车厘子/樱桃、鲜花等特殊商品 | 签收后**24小时**内 |

### 4.1.2 坏损赔付标准
按商品腐烂变质及短缺程度执行阶梯赔付：

| 问题比例（数量/重量） | 赔付比例 |
|---------------------|---------|
| 1% - 10% | 订单实际支付金额的10% |
| 11% - 30% | 订单实际支付金额的30% |
| 31% - 50% | 订单实际支付金额的50% |
| 51% 以上 | 订单实际支付金额的100% |

### 4.1.3 举证要求
- 需上传物流面单（证明签收时间）
- 需上传商品破损/变质细节图（证明商品真实损坏）
- 需上传商品破损/变质比例图（判断坏损比例）
- 针对保质期类问题，需上传生产日期/有效期图片
- **逾期未举证的，不予受理**

### 4.1.4 不适用情形
- 因个人口味或批次差异导致的口感、气味差异（非腐烂变质）
- 因使用或保管不当导致的质量问题、变质
- 部分生鲜需放置自然成熟（如榴莲、香蕉、猕猴桃等），属正常现象
- 用户无正当理由拒收导致商品损伤、变质
- 受季节、气候、生长环境等因素影响的批次差异

### 4.1.5 生鲜商品不适用七天无理由
- 生鲜类商品属于鲜活易腐类，**不支持七日无理由退货**
- 仅支持质量问题（腐坏、变质、死亡）导致的售后

## 4.2 预包装食品

### 4.2.1 退换货条件
- 商品一次性密封外包装**未拆封**（可支持无理由退货的前提）
- 商品在保质期内
- 储存条件符合要求

### 4.2.2 不适用情形
- 外包装已拆封（食品拆封后不支持无理由退货）
- 临近保质期（已明示的）
- 进口巧克力等易受温湿度影响的特殊食品
- 因储存不当导致的变质（消费者责任）

### 4.2.3 质量问题认定
- 包装破损导致污染
- 霉变、虫蛀
- 异物混入
- 超过保质期
- 与标注成分不符
- 真空包装漏气失效

## 4.3 酒水/饮料

### 4.3.1 退换货条件
- **啤酒**：一次性密封外包装未拆封，可支持无理由退货
- **其他酒水**（白酒、红酒等）：不支持七天无理由退货
- 酒水存在质量问题（如漏液、变质、沉淀异常）的，适用质量问题售后

### 4.3.2 特殊要求
- 红酒需恒温运输，温度异常导致的变质不纳入商家责任
- 高价值名酒需全程溯源，包装防伪码完整

## 4.4 保健食品/滋补品

### 4.4.1 退换货条件
- 一次性密封外包装未拆封
- 燕窝、海参/参类商品：不支持七天无理由退货
- 冬虫夏草：不支持七天无理由退货

### 4.4.2 质量问题认定
- 霉变、虫蛀
- 超过保质期
- 包装密封性被破坏
- 与标注成分含量不符

## 4.5 AI审核要点
1. 判断商品是否属于生鲜/食品类 → 生鲜不支持无理由退货
2. 审核申请时间 → 是否在签收后规定时效内（48h/6h/24h）
3. 审核举证材料 → 是否有清晰的破损/变质照片+物流面单
4. 判断坏损比例 → 按阶梯赔付标准计算赔付金额
5. 区分"自然成熟"与"变质" → 前者属正常现象，后者属售后范围
6. 区分"口味差异"与"质量问题" → 口味差异不纳入售后
7. 判断是否因消费者储存不当导致 → 消费者责任不赔付
8. 酒水类特别规则：啤酒密封完整可退，白酒红酒不支持无理由

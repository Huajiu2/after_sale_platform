# 四、人工审核&判例迭代文档

## 4.1 人工审核流程

### 4.1.1 审核入口
- AI审核判定为"待人工"的工单（60 ≤ confidence < 85）
- AI审核判定为"待人工"（低置信度，confidence < 60）
- 消费者对AI审核结果不满发起申诉
- 必须转人工的特殊场景工单

### 4.1.2 审核步骤
```
Step 1: 查看工单基本信息（ticketNo, orderNo, afterSaleType）
Step 2: 查看订单信息（商品、金额、下单时间）
Step 3: 查看消费者申请原因及举证材料
Step 4: 查看AI审核结论及置信度
Step 5: 检索相关规则（RAG辅助）
Step 6: 查看历史判例（如有）
Step 7: 做出审核决定
Step 8: 填写审核备注（人工备注）
Step 9: 提交审核结果
```

### 4.1.3 审核决定类型
| 决定 | 适用场景 |
|-----|---------|
| **同意售后** | 符合退货/退款条件，消费者举证充分 |
| **驳回售后** | 不符合退货条件，或属于免责情形 |
| **部分退款** | 商品部分损坏，或配件缺失（建议退款比例） |
| **换货处理** | 质量问题且消费者要求换货，商品在换货期内 |

## 4.2 人工审核要点

### 4.2.1 信息核实
- 核对订单信息是否匹配
- 核对售后类型是否正确
- 核实消费者身份与订单购买者一致
- 核对申请时效是否在允许范围内

### 4.2.2 举证材料审核
- 照片/视频是否清晰可辨
- 照片拍摄时间是否与申请时间一致
- 照片内容是否能证明所述问题
- 是否存在P图、伪造嫌疑
- 物流面单信息是否完整

### 4.2.3 消费者画像参考
- 查看消费者历史售后记录
- 是否存在频繁退换货行为
- 是否存在恶意售后历史
- 消费者信用等级（如有）

### 4.2.4 商家视角考量
- 商家是否已与消费者协商
- 商家是否认可售后申请
- 商家售后处理历史记录

## 4.3 优质判例生成标准

### 4.3.1 判例筛选条件
符合以下条件的人工审核记录应生成优质判例：
1. **人工备注非空**：审核员填写了详细的审核理由和处理说明
2. **规则引用明确**：审核备注中引用了具体的规则条款
3. **争议性强**：该工单在AI审核阶段置信度较低（< 70%）
4. **典型性**：代表了某一类常见但容易争议的场景
5. **无申诉/申诉维持**：该审核结果未被推翻，或申诉后维持原判

### 4.3.2 判例数据结构
```json
{
  "ticketNo": "SH20260715001",
  "caseCategory": "数码3C_激活争议",
  "caseTitle": "手机已激活但外观完好要求退货",
  "caseContent": "售后类型：仅退款|商品：XXX手机|申请原因：不想要了|审核结果：驳回|人工备注：手机已激活，无质量问题，不适用7天无理由退货",
  "finalResult": "驳回",
  "manualRemark": "手机已激活，无质量问题，不适用7天无理由退货",
  "applicableRuleRef": "02-数码3C类售后规则.md#2.1.2",
  "isActive": true
}
```

### 4.3.3 判例质量评级
| 等级 | 标准 | 保留期限 |
|-----|------|---------|
| ★★★ | 规则引用明确+典型场景+无申诉 | 永久 |
| ★★☆ | 规则引用明确+典型场景 | 1年 |
| ★☆☆ | 一般判例 | 6个月 |

## 4.4 判例迭代机制

### 4.4.1 判例效用
- 优质判例作为RAG检索的来源之一，辅助AI审核决策
- 判例相似度 ≥ 80% 时，可直接引用判例结论
- 判例相似度 60%-80% 时，作为参考依据

### 4.4.2 判例淘汰
- 因法律法规更新导致失效的判例 → 立即下架
- 因平台规则变更导致失效的判例 → 立即下架
- 超过保留期限的判例 → 自动归档
- 被后续判例推翻的判例 → 标记为"已推翻"

### 4.4.3 自迭代流程
```
人工审核产生判例 → 判例进入quality_case表 → 生成向量embedding
→ 后续AI审核时检索判例 → 匹配相似场景 → 提升审核准确率
→ 减少需人工审核的工单量 → 人工审核更多精力处理高价值判例
```

## 4.5 人工审核质量监控

### 4.5.1 监控指标
| 指标 | 目标值 |
|-----|-------|
| 审核准确率 | ≥ 98% |
| 单均审核时效 | ≤ 5分钟 |
| 申诉率 | ≤ 5% |
| 申诉维持率 | ≥ 80% |
| 判例转化率 | ≥ 30%（有人工备注的工单） |

### 4.5.2 抽检复核
- 每名审核员每日抽检前一日审核量的10%
- 低置信度AI转人工的工单抽检率 ≥ 20%
- 申诉处理的工单100%复核

# 二、服饰鞋包类商品售后专项规则

## 3.1 服饰类

### 3.1.1 退换货时限
- 7日无理由退货
- 15日质量问题换货

### 3.1.2 完好标准
- 商品无显著穿戴痕迹、无洗涤、无沾染化妆品（如口红、粉底等）
- 商标吊牌齐全、未被摘除
- 包装袋/盒完好
- 无异味（香水、烟味、体味等）
- 无污渍、无破损

### 3.1.3 不适用七天无理由退货的情形
- 内裤、袜子、打底袜、丝袜、塑身衣等**贴身衣物**
- 保暖衣、男士内衣、女士内衣
- 乳贴、插片/胸垫
- 定制类服饰
- 商品已修改尺寸、已洗涤

### 3.1.4 质量问题判定
- 面料破损、抽丝、起球严重（超出正常穿着范围）
- 缝合处开线、脱缝
- 染色牢度不达标（正常洗涤后褪色）
- 尺码与描述严重不符（超出合理误差范围）
- 面料成分与标注不符
- 拉链、纽扣等配件损坏

### 3.1.5 举证要求
- 质量问题需提供照片/视频证据
- 色差问题需提供对比照片（因拍摄灯光、显示器差异导致的轻微色差不属于质量问题）
- 尺码问题在标准误差范围内（一般±2cm）不属于质量问题

## 3.2 鞋靴类

### 3.2.1 退换货条件
- 商品无穿着痕迹、无磨损
- 鞋底无磨损、无划痕
- 鞋盒完好无损（鞋盒具有特殊价值，需保持完整）
- 配件齐全（鞋带、鞋垫、鞋撑等）
- 无异味

### 3.2.2 不适用情形
- 鞋底有明显磨损（已实际穿着）
- 鞋盒严重破损
- 已进行过修理或改动
- 定制鞋款

### 3.2.3 质量问题判定
- 开胶（非人为）
- 鞋面材质破裂
- 左右脚不对称
- 鞋跟脱落
- 鞋内材质褪色

## 3.3 箱包/皮具类

### 3.3.1 退换货条件
- 商品无显著使用痕迹
- 无磨损、无划痕
- 五金件保护膜未撕除
- 吊牌、防尘袋、身份卡齐全
- 无异味

### 3.3.2 不适用情形
- 五金件有明显磨损或划痕
- 包内有明显使用痕迹
- 身份卡/保卡缺失
- 已刻字或DIY定制

### 3.3.3 特殊说明
- 奢侈品箱包需保留专柜包装及全套附件
- 高价值箱包建议录制开箱视频作为退换货凭证
- 二手/中古商品按"所见即所得"原则，以商品详情页描述为准

## 3.4 AI审核要点
1. 检查是否为贴身内衣/袜子 → 拆封后不支持无理由退货（质量问题除外）
2. 检查商标吊牌是否完整 → 缺失则不完好
3. 审核"穿过/用过"的判定依据 → 鞋底磨损、衣服洗涤、化妆品沾染
4. 区分质量问题和人为损坏 → 人为损坏不纳入售后
5. 审核色差投诉 → 轻微色差不属于质量问题，严重色差需商家举证说明
6. 尺码投诉 → 在标准误差范围内（±2cm）不属于质量问题
7. 涉及过敏的 → 需提供医院证明
